# Thorium

**Thorium** is a performance-focused Minecraft optimization mod and a fork of [Rubidium](https://modrinth.com/mod/rubidium), bringing the optimization concepts of Sodium to deliver smoother gameplay and improved rendering performance.

Built with performance in mind, Thorium aims to optimize Minecraft's rendering engine, reduce unnecessary performance overhead, and provide a smoother experience, especially on low-end and mid-range devices.

### Features
- **Improved Rendering Performance** – Optimizes Minecraft's rendering pipeline for better FPS.
- **Smoother Gameplay** – Helps reduce rendering overhead and improve overall game responsiveness.
- **Performance Focused** – Designed with low-end and mid-range hardware in mind.
- **Sodium-Based Optimization** – Builds upon the performance-oriented foundations of Sodium and Embeddium through Rubidium.
- **Open Source** – Community-driven development and contributions.
- **Mods Compatible** - Works with most of the mods.

### About
Thorium is an fork of Rubidium making improvements and adding better mod compatibility, aiming to make Minecraft more enjoyable by delivering better performance without compromising the gameplay experience.
